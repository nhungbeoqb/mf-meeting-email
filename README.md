One line, 112 characters, one joke about a meeting that should have been an email:

> My out-of-office reply went to the meeting in my place; it said nothing, agreed to everything, and got promoted.

## How it works

`main.py` (Python 3.13 standard library only) writes that single line to `$OUTPUT_DIR/entry.txt`, with a self-check mirroring the sealed gate: 1–200 characters, one line, not only white space, no trailing newline. The output is deterministic — two runs produce byte-identical files.

```sh
OUTPUT_DIR=/output python3 main.py
```
